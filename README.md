# sa-group-website

New website for Standard Alloys India Pvt. Ltd. and Surge Alloys Pvt. Ltd., Ajmer, India.

**Review link:** https://sorabbaheti-droid.github.io/sa-group-website/

- `index.html` – review hub listing the design concepts
- `concepts/a`, `concepts/b`, `concepts/c` – the three concepts (static HTML)
- The site is static and served by GitHub Pages. The RFQ form is an ERPNext Web Form (saconnect.frappe.cloud) embedded in the page; submissions become Leads in ERPNext with drawings attached.
